# Dois Ouvidos (pasta para o site)

- `index.html`: página principal
- `css/style.css`: estilos
- `js/app.js`: lógica do app
- `vercel.json`, `netlify.toml`, `.nojekyll`: configurações opcionais de hospedagem

## Como usar no seu site

1. Envie a pasta inteira (mantendo `css/` e `js/`) para o seu servidor ou hospedagem.
2. Abra `index.html`. Para colocar em um subcaminho (ex.: `seusite.com/dois-ouvidos/`), basta enviar a pasta com esse nome.

Observações:
- As fontes vêm do Google Fonts; sem internet o app usa fontes do sistema.
- O mural coletivo só funciona dentro do claude.ai. No seu site ele mostra o aviso de indisponível; o resto funciona normalmente.
